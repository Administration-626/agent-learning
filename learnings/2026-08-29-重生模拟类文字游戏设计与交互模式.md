# 重生模拟类文字游戏设计与交互模式

Date: 2026-08-29
Agent: Antigravity

## 背景 (Background)
在开发与重构纯前端文字重生模拟游戏（如希腊神话版《冥府投胎处》）时，总结如何设计高爽感、强交互、无视觉抖动的人生重开模拟器架构与避坑指南。

## 问题分析 (Problem Analysis)
1. **纯被动阅读导致参与感缺失**：
   - 早期设计将重大抉择事件概率设得过低（<10%），玩家整局几乎都在“被动看随机流水账”，无法主动影响命运走向。
2. **布局伸缩与视线跳跃（Layout Shift 痛点）**：
   - 将选项交互按钮动态塞入正在滚动的文字日志流内部，导致每次触发抉择时文字被猛烈顶起；选完后按钮销毁，文字又瞬间回弹，严重破坏阅读节奏与视觉舒适度。
3. **状态未重置与静默崩溃**：
   - 状态对象属性命名不一致（如声明 `usedEvents` 却在循环中读取 `used.includes`），导致控制台抛出未捕获异常中断执行，表现为“点击下一岁毫无反应”。
4. **成长曲线平淡、缺乏爽感爆发**：
   - 数值增减过于保守（全是一成不变的 +1/-1），缺少高属性时的史诗级异象与神话名场面反馈。

## 解决方案与核心架构规范 (Solution & Architecture)

### 1. 日志流与交互区彻底解耦（解消除 Layout Shift）
* **纯净日志流 (`#feed`)**：固定高度，只负责单向向下平滑打印年龄日志和已完成的抉择记录，**严禁插入任何临时操作按钮**。
* **独立抉择面板 (`#choice-box`)**：放置在日志框正下方的固定操作区。
  * 抉择触发时：日志流打印 `【重大抉择】...`，底部操作栏切换为选项面板，自动播放定时器自动暂停；
  * 点击选项后：选项面板平滑收起，底部恢复步进按钮，日志流追加 `▸ 你的决定：...` 和对应结算效果，无缝恢复推进。

### 2. 强互动：重大人生抉择体系 (Interactive Choices)
* **概率提升与分段保底**：抉择概率提升至 30%~40%，并在童年（4-5岁）、少年（12-14岁）、青年（20-25岁）、壮年（36-45岁）、老年（58岁+）设立**保底重大转折抉择**。
* **高收益/高风险设计**：选项直接带来大额属性、寿命延长（+15~30岁）、转生结局影响或死因逆转（如深夜与死神拼酒改写生死簿）。

### 3. 高属性神力觉醒机制 (High-Stat Explosions)
* 设置属性阈值触发器（如单项属性 $\ge 8$）：
  * 勇武 $\ge 8$：徒手生撕猛兽，全希腊传颂半神之名；
  * 智慧 $\ge 8$：创立哲学学派推翻旧秩序，成为一代宗师；
  * 颜值 $\ge 8$：引发神界女神下凡打赌，万众膜拜。
* 终局根据属性峰值、财富积蓄与寿命综合评定【神话级史诗/传奇英雄/平淡安康】并匹配高逼格转生去向（荣登奥林匹斯主神殿、英雄岛极乐乐土等）。

### 4. 生命周期严密重置 (State Management)
* 每次新人生初始化必须显式重置：
  ```javascript
  R.used = [];
  R.pendingChoice = null;
  R.ended = false;
  R.age = 0;
  ```
* 所有的 step 推进前必须做 `if (R.pendingChoice) return;` 守卫，避免在等待玩家抉择时误步进。

## 验证方法 (Verification)
1. **自动化无头测试**：编写多局模拟脚本（如 `test-rebirth.js`），模拟随机加点、随机选天赋并全自动决策，验证 0~100+ 岁全生命周期无死循环、无未捕获异常。
2. **DOM 视口与交互断言**：验证抉择出现时日志流高度稳定，选项面板显示在固定槽位，点击后日志正确追加且自动播放可安全唤醒。
